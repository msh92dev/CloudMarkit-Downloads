# CloudMarkit POS pilot downloads

Official pilot packages for Windows x64 and Android. These are trial builds for dedicated test stores and hardware compatibility testing.

Windows: extract the portable ZIP and launch CloudMarkit.Desktop.App.exe. No commercial code signature; device policy may block execution.

Android: locally signed pilot APK, distributed outside Google Play.

Verify downloads against SHA256SUMS.txt. Test Arabic receipts, supported paper width, barcode input, returns and reconnect synchronization using sample data. Do not use live customer records for the pilot.
